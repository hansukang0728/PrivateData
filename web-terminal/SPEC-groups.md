# 터미널 그룹 (부모–자식) 사양

2026-09-20 · 질의응답으로 확정. `PLAN.md`의 6장(터미널 탭)을 이 문서가 대체한다.

---

## 1. 용어

| 용어 | 정의 |
|---|---|
| **그룹(Group)** | 부모 터미널 1개 + 자식 터미널 0~N개. 이 앱의 작업 단위 |
| **부모(Parent)** | 그룹을 대표하는 터미널. 자식을 만들 수 있는 유일한 주체 |
| **자식(Child)** | 부모에서 파생된 터미널. **자식은 자식을 만들 수 없다** (족보 깊이 2단계 고정) |
| **단독 터미널** | 자식이 0개인 그룹. 그냥 탭 하나 |
| **접힌 자식** | 화면 자리를 양보하고 탭 바에만 남아 있는 자식. 세션은 살아 있음 |

> **핵심 제약 — 손자는 없다.** 무한 중첩 대신 "부모 하나에 자식 여럿"으로 평평하게 간다.
> 더 깊은 구조가 필요하면 새 그룹을 만든다.

## 2. 화면 배치

부모가 왼쪽을 넓게 쓰고, 자식들이 오른쪽에 위아래로 쌓인다.

```
┌──────────────────────────┬──────────────────┐
│                          │ └ 2025-09-20     │  자식 1
│  data                    ├──────────────────┤
│  (부모 · 60%)            │ └ output         │  자식 2
│                          ├──────────────────┤
│                          │ └ docs           │  자식 3
└──────────────────────────┴──────────────────┘
```

- 좌우 비율 기본 60:40, 경계선 드래그로 조절. 그룹별로 기억
- **화면에 보이는 자식은 최대 3개** (설정에서 2~4). 넘으면 §5의 접기 규칙
- 자식이 0개면 부모가 창 전체를 쓴다
- 포커스된 페인은 헤더에 강조색 띠

## 3. 탭 바 — 그룹만 선다

**탭 바에는 부모(그룹)만 올라간다.** 자식은 화면 페인이 곧 자기 자리라 탭이 중복이다.
그룹에 자식이 있으면 탭에 숫자 배지가 붙는다.

```
[ ■ HansuKangDailyData ③ ] [ ■ git ] [＋]
```

| 동작 | 결과 |
|---|---|
| 탭 클릭 | 그 그룹이 통째로 화면에 — 부모 + 자식 페인이 함께 뜬다 |
| 탭 더블클릭 / 우클릭 | 이름 편집 / 그룹 메뉴 |
| 탭 × | 그룹 닫기 (자식 포함, 실행 중이면 확인) |
| 숫자 배지 | 이 그룹이 거느린 자식 수 |

### 자식은 어디서 다루나

| 하고 싶은 것 | 어디서 |
|---|---|
| 이동 | 페인 클릭, 또는 `Alt+1~3` (번호는 페인 헤더에 표시) |
| 이름 바꾸기 | 페인 헤더 이름 더블클릭, 또는 `F2` |
| 접기 / 승격 / 닫기 | 페인 헤더 우클릭, 또는 헤더의 × |
| 접힌 자식 되돌리기 | 오른쪽 열 아래 **접힌 막대** 클릭 |

**접힌 자식은 사라지지 않는다.** 자식 열 맨 아래에 25px짜리 막대로 남아
번호·이름·경로·실행 표시(●)를 달고 있고, 누르면 자리 교대로 화면에 돌아온다.
탭 바에서 자식을 뺐기 때문에, 이 막대가 접힌 자식의 유일한 입구다.

### 자식 구분

자식마다 **색과 번호가 고정**된다 (청록 · 자홍 · 노랑 · 초록 순).
페인 헤더 왼쪽 색 띠, 번호 배지, 접힌 막대가 모두 같은 색을 쓴다.
포커스된 페인은 테두리와 헤더가 자기 색으로 물들어, 지금 어디에 타이핑 중인지 색만 봐도 안다.

## 4. 자식 만들기

입구는 **둘**:

1. **부모 페인 헤더의 ⊕ 버튼** — **자식 페인에는 ⊕ 가 없다.** 누가 부모인지 화면에서 바로 드러난다
2. **탐색기에서 폴더 우클릭 → "자식 터미널로 열기"** — 현재 포커스된 그룹의 부모 밑에 붙는다

⊕ 를 누르면 부모의 현재 폴더 기준으로 **하위 폴더 목록**이 뜬다:

```
┌─ 자식 터미널 열기 ──────────┐
│ ▸ 현재 폴더 그대로 (data)   │   ← 첫 항목
│ ▸ 2025-09-18                │
│ ▸ 2025-09-19                │
│ ▸ 2025-09-20                │
│ ─────────────────────────── │
│ ▸ 다른 폴더 찾아보기…        │
└─────────────────────────────┘
```

자식은 **깨끗한 새 셸**로 시작한다. 부모의 환경변수·venv·히스토리를 물려받지 않는다.

## 5. 한도와 접기

자식이 이미 3개인데 ⊕ 를 또 누르면 — **막지 않는다.** 새 자식을 화면에 넣고,
**가장 오래 안 쓴 자식을 접어** 탭 바에만 남긴다.

접기 우선순위 (뒤로 갈수록 보호):
1. 마지막 입력이 가장 오래된 자식
2. **실행 중인 프로세스가 있는 자식은 마지막까지 보호** — 돌아가는 크롤러가 눈앞에서 사라지면 안 된다
3. 방금 포커스됐던 자식

접힌 자식은 자식 열 맨 아래에 막대로 내려간다. 세션은 그대로 살아 있어서 출력도 계속 쌓이고,
막대를 누르면 다시 화면으로 올라온다 (대신 가장 오래 안 쓴 자식이 내려간다).

## 6. 족보 규칙

- 자식이 **어디로 cd 하든 자식으로 남는다.** 관계는 "어디서 태어났는가"만 의미한다
  - `data`에서 태어난 자식이 `C:\Windows`로 가도 여전히 그 그룹 소속
- 부모가 cd 해도 자식은 따라가지 않는다 (연동 없음)
- **부모를 닫으면 자식도 모두 닫힌다.** 실행 중인 프로세스가 있으면 목록을 보여주고 확인받는다
- 자식을 닫으면 그 페인만 사라지고, 접혀 있던 자식이 한 칸 올라온다
- 자식 탭을 그룹 밖으로 드래그하면 독립 그룹(새 부모)이 된다 — 승격

## 7. 작업셋 — 자동 저장만

이름 붙인 스냅샷은 만들지 않는다. 앱이 알아서 기억하고 다음에 그대로 띄운다.

**저장하는 것**: 그룹 구성(부모–자식 관계), 각 터미널의 폴더·탭 이름·셸 종류, 페인 비율, 접힘 상태, 탭 순서, 테마
**저장하지 않는 것**: 실행 중이던 명령, 셸 히스토리, 스크롤백 내용

저장 시점은 구조가 바뀔 때마다(디바운스 500ms) + 창 닫을 때. 저장 위치는 `%APPDATA%\poshdeck\workspace.json`.

## 8. 상태 모델

```js
{
  groups: [{
    id, parentId,
    children: [termId, ...],        // 최대치 없음. 화면 표시만 제한
    visibleChildren: [termId, ...], // 최대 3개 (설정 2~4)
    ratio: 0.6                      // 부모 페인 가로 비율
  }],
  terminals: {
    [id]: {
      id, groupId, role: "parent" | "child",
      name,                         // 사용자가 바꾼 이름
      cwd, birthCwd,                // 현재 폴더 / 태어난 폴더 (족보 표시용)
      shell: "pwsh" | "powershell" | "cmd" | "wsl",
      pid, running: bool,           // 접기 보호 판단
      lastInputAt                   // 접기 LRU 판단
    }
  },
  activeGroupId, focusedTermId
}
```

`birthCwd`를 따로 들고 있으면 "이 자식은 원래 어디서 났는가"를 툴팁으로 보여줄 수 있다 —
자식이 멀리 cd 했을 때 족보가 왜 그런지 설명된다.

## 9. 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+D` | 포커스된 **부모**에서 자식 만들기 (자식 페인에서 누르면 그 부모 기준) |
| `Alt+←/→/↑/↓` | 페인 간 포커스 이동 |
| `Alt+1~3` | 자식 번호로 바로 이동 · `Alt+0` 은 부모로 |
| `Ctrl+Tab` | 같은 그룹 안에서 터미널 순환 |
| `Ctrl+Shift+Tab` | 그룹 간 이동 |
| `Ctrl+W` | 포커스된 터미널 닫기 (부모면 그룹 전체 확인) |
| `F2` | 포커스된 페인 이름 편집 |
| `Ctrl+Shift+E` | 접힌 자식 펼치기 |
