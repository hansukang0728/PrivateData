PoshDeck 사용법
================================================================
Chrome 에서 여는 PowerShell 작업대.
왼쪽은 파일 탐색기, 오른쪽은 부모-자식으로 묶인 터미널 그룹.


[ 1. 처음 실행하기 ]
----------------------------------------------------------------
  poshdeck.bat 을 더블클릭하세요. 그게 전부입니다.

  - 설치할 것도, 내려받을 것도 없습니다.
  - 곧바로 Chrome 이 저절로 열립니다.
  - 검은 콘솔 창은 서버입니다. 닫지 마세요.
  - 완전히 끄려면 그 검은 창에서 Ctrl+C 를 누릅니다.

  처음이라면 진단.bat 을 먼저 돌려보세요.
  파이썬 버전, 윈도우 버전, 셸이 제대로 뜨는지까지 한 번에 확인하고
  문제가 있으면 어디가 막혔는지 알려줍니다.

  필요한 것: Python 3.8 이상 (대부분의 PC 에 이미 있습니다)

  확인하려면 명령 프롬프트에서:
      py -3 --version

  pip 로 설치할 패키지는 하나도 없습니다. 파이썬 기본 기능만 씁니다.
  Node.js 는 필요 없습니다. (있으면 그쪽으로도 뜨긴 합니다)


[ 2. 화면 구성 ]
----------------------------------------------------------------
  +----------+---------------------+----------------------+
  | 탐색기   |  부모 터미널         | (1) data     * 실행  |
  |          |                     +----------------------+
  | 폴더     |  PS C:\...>          | (2) output           |
  | 목록     |                     +----------------------+
  |          |                     | (3) docs             |
  |          |                     | | (4) logs   ^ 펼치기 |
  +----------+---------------------+----------------------+

  - 왼쪽 큰 창이 "부모", 오른쪽에 쌓이는 작은 창들이 "자식"입니다.
  - 자식마다 번호와 색이 붙습니다. 탭 바의 숫자는 자식이 몇 개인지입니다.
  - 자식이 화면 한도(기본 3개)를 넘으면, 가장 오래 안 쓴 자식이
    맨 아래 얇은 막대로 접힙니다. 접혀도 그 터미널은 계속 살아 있습니다.
  - 무언가 실행 중인 터미널(* 실행 표시)은 접히지 않고 보호됩니다.


[ 3. 자주 쓰는 동작 ]
----------------------------------------------------------------
  자식 터미널 만들기
      부모 창 위쪽 [+] 버튼 -> 하위 폴더 고르기
      또는 Ctrl+Shift+D

  다른 폴더에서 터미널 열기
      왼쪽 탐색기에서 폴더 우클릭
      -> "자식 터미널로 열기"  (지금 그룹에 붙임)
      -> "새 그룹으로 열기"    (따로 떼어 새 탭)

  새 그룹 만들기          탭 바의 [+]  또는 Ctrl+Shift+T
  창 사이 이동            창을 클릭  또는 Alt+1 ~ Alt+4 (부모는 Alt+0)
  이름 바꾸기             창 제목 더블클릭  또는 F2
  접힌 자식 펼치기        맨 아래 막대를 클릭
  접기 / 승격 / 닫기      창 제목 줄에서 우클릭
  복사                    드래그로 선택한 뒤 Ctrl+C
                          (선택한 게 없으면 Ctrl+C 는 원래대로 '중단')
  붙여넣기                Ctrl+V   또는 터미널에서 우클릭 -> 붙여넣기
  터미널 우클릭           복사 / 붙여넣기 / 전체 선택 / 찾기 / 화면 지우기

  글꼴 바꾸기             오른쪽 위 [가 글꼴] — 글꼴과 줄 간격
                          설치되지 않은 글꼴은 (없음) 으로 표시됩니다
  글자 크기               오른쪽 위 [A-] [A+]  또는 Ctrl + / Ctrl -
                          Ctrl+0 으로 기본값(13px)
                          창 위에서 Ctrl+휠 = 그 창만 조절
  터미널 안에서 찾기      Ctrl+F
  탐색기 접기/펴기        Ctrl+B
  테마 바꾸기             오른쪽 위 동그라미 아이콘 (8가지)
  창 크기 조절            탐색기와 터미널 사이 세로선을 좌우로 끌기
                          (더블클릭하면 원래 폭으로)
                          부모와 자식 사이 세로선을 좌우로 끌기
                          자식들 사이 가로선을 위아래로 끌기
                          (자식이 하나도 없으면 부모가 창 전체를 씁니다)


[ 3-1. 다른 드라이브 / 네트워크 폴더 보기 ]
----------------------------------------------------------------
  탐색기 맨 아래에 드라이브 단추가 줄지어 있습니다.

      [ ⌂ 홈 ]  [ C: ]  [ D: ]  [ E: ]  [ 경로… ]

  - 단추를 누르면 그 드라이브로 탐색기가 옮겨갑니다.
  - [경로…] 를 누르면 경로를 직접 칠 수 있습니다.
    네트워크 폴더도 됩니다:   \\서버이름\공유폴더
  - 탐색기 맨 위의 현재 경로를 눌러도 같은 입력창이 뜹니다.
  - 위쪽 화살표는 상위 폴더로 갑니다.


[ 4. 탐색기에서 우클릭하면 ]
----------------------------------------------------------------
  맨 위의 [Windows 메뉴 열기] 를 누르면 탐색기에서 보던 그 메뉴가
  그대로 뜹니다. TortoiseGit, 7-Zip, 반디집 같이 설치해 둔 프로그램이
  끼워 넣은 항목까지 전부 나옵니다.

      Shift + 우클릭  ->  Windows 메뉴를 바로 (확장 항목까지)

  그 아래는 자주 쓰는 것들을 빠르게 쓰라고 따로 둔 항목입니다:
  열기 / 자식 터미널로 열기 / 새 그룹으로 열기 / 새로 만들기 /
  잘라내기 / 복사 / 붙여넣기 / 이름 바꾸기 / 삭제(휴지통) /
  경로 복사 / Windows 탐색기에서 표시 / 속성

  삭제는 기본이 휴지통입니다. 영구 삭제가 아닙니다.


[ 4-1. 자주 쓰는 명령 버튼 ]
----------------------------------------------------------------
  화면 맨 아래 [명령] 줄에 버튼을 만들어 두고 한 번에 실행합니다.

      클릭          지금 보고 있는 창에서 실행
      Shift+클릭    입력만 해두고 멈춤 (뒤에 인자를 더 붙일 때)
      우클릭        편집 / 복제 / 순서 바꾸기 / 삭제
                    "그룹의 모든 창에서 실행" 도 여기 있습니다
      [+]           새 명령 등록
      [모든 창]     켜두면 클릭 한 번에 그룹의 모든 창으로 보냅니다

  명령 안에 {cwd} 를 쓰면 그 터미널의 현재 폴더로 바뀝니다.
      예)  python {cwd}\crawl_complex.py

  등록한 명령은 자동 저장되어 다음에도 그대로 있습니다.


[ 5. 저장되는 것 ]
----------------------------------------------------------------
  그룹 구성, 각 터미널의 폴더와 이름, 창 배치, 테마, 글자 크기는
  자동으로 저장되어 다음에 열면 그대로 복원됩니다.
  (실행 중이던 명령과 화면에 찍힌 내용은 복원하지 않습니다.)

  설정 파일 위치:
      %LOCALAPPDATA%\poshdeck\workspace.json   작업셋
      %LOCALAPPDATA%\poshdeck\config.json      설정
      %LOCALAPPDATA%\poshdeck\psinit.ps1       셸 초기화


[ 6. 설정 바꾸기 ]
----------------------------------------------------------------
  %LOCALAPPDATA%\poshdeck\config.json 을 메모장으로 열어서:

      {
        "defaultShell": "pwsh",
        "port": 7788,
        "roots": []
      }

  defaultShell  기본 셸. "pwsh"(PowerShell 7) / "powershell"(5.1)
                / "cmd" / "wsl"
  port          서버 포트. 충돌하면 알아서 다음 번호를 씁니다
  roots         접근 허용 폴더. 비워 두면 제한 없음(C: 전체).
                좁히려면 예: ["C:\\Users\\hansu\\HansuKangDailyData"]


[ 7. 잘 안 될 때 ]
----------------------------------------------------------------
  무엇이든 이상하면 먼저:  진단.bat 더블클릭
  그 창에 나온 내용을 그대로 복사해서 알려주시면 됩니다.

  "Python 도 Node 도 찾을 수 없습니다" 라고 나옴
      -> 명령 프롬프트에서 py -3 --version 을 쳐보세요.
         아무 것도 안 나오면 Microsoft Store 에서 "Python" 을 검색해
         설치할 수 있습니다. 관리자 권한이 필요 없습니다.

  "ConPTY(CreatePseudoConsole)가 없습니다" 라고 나옴
      -> Windows 10 1809(2018년 하반기) 이상이 필요합니다.
         윈도우 버전을 확인해 주세요 (winver 명령)

  터미널이 비어 있고 "세션이 종료되었습니다" 라고 나옴
      -> PowerShell 7 이 없을 수 있습니다.
         config.json 에서 "defaultShell": "powershell" 로 바꾸세요

  프롬프트에 이상한 글자가 섞여 보임
      -> %LOCALAPPDATA%\poshdeck\psinit.ps1 을 지우면 다시 만들어집니다

  브라우저에 401 이라고 뜸
      -> 검은 콘솔 창에 찍힌 주소(토큰 포함)를 그대로 복사해 들어가세요

  한글이 깨짐
      -> 글꼴을 Cascadia Mono 나 D2Coding 으로 바꿔 보세요

  포트가 이미 쓰이고 있음
      -> 자동으로 다음 포트를 찾습니다. 콘솔에 찍힌 주소를 보세요


[ 8. 알아두실 점 ]
----------------------------------------------------------------
  - 이 서버는 내 PC 에서만(127.0.0.1) 뜹니다. 밖에서는 접속 못 합니다.
  - 실행할 때마다 1회용 토큰이 새로 발급됩니다.
    콘솔에 찍힌 주소는 남에게 주지 마세요.
  - 이 프로그램은 Windows 에서 아직 충분히 검증되지 않았습니다.
    문제가 생기면 검은 콘솔 창의 내용을 그대로 알려주세요.


  자세한 설계 문서: PLAN.md , SPEC-groups.md
  개발자용 설명서:  README.md

  서버 코드는 pyserver 폴더에 있습니다 (파이썬, 설치 불필요).
  Node 를 쓰는 환경이라면 server 폴더의 자바스크립트 서버로도 돕니다.
